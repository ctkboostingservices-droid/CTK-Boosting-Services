# CTK Boosting Services Website

This version uses the supplied CTK Boosting Services logo as the main visual identity and updates the public website to a black / gold / white premium style.

## Files
- `index.html` — public website
- `styles.css` — responsive black/gold design
- `script.js` — public-site rendering and interactions
- `app-data.js` — editable demo data
- `admin.html`, `admin.js`, `admin.css` — demo admin panel with Save Changes
- `ctk-boosting-services-.srilanka.jpg` — supplied CTK logo
- `supabase-schema.sql` — schema for the planned Supabase connection
